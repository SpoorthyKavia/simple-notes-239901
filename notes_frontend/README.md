# Retro Notes (Frontend)

A simple notes application built with React (client-only) that supports:

- Create, edit, delete notes (CRUD)
- List and view notes
- Search notes by title/content
- Persistence via browser `localStorage` (no backend required)

## Run locally

```bash
npm install
npm start
```

Then open the printed local URL.

## Data

Notes are stored in your browser under the key `retro_notes__v1`.
Clearing site data/localStorage will remove notes.
